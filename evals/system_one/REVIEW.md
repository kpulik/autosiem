## Rationale per case

- **`tp-ransomware-precursor`** - Shadow copies deleted, then ransomware binary encrypts files. Active destruction in progress; containment now.
- **`tp-mimikatz-lsass`** - Mimikatz dumps LSASS on a user workstation. Credential theft means every logged-on account is compromised.
- **`tp-ntds-extraction`** - NTDS.dit copied off a domain controller. Full domain compromise; every credential must be treated as stolen.
- **`tp-phish-to-encoded-powershell`** - Phishing email, then encoded PowerShell on the recipient's machine. Delivery plus execution: the endpoint is compromised.
- **`tp-password-spray-then-success`** - Failed logins from one external IP, then a success. A spray that ends in a success is an account takeover until disproven.
- **`tp-certutil-download`** - cmd.exe uses certutil to pull an executable from a bare IP. certutil as a downloader from a raw IP has almost no benign use.
- **`tp-wmic-lateral-movement`** - WMIC spawns a process on a finance server from a workstation. Lateral movement in progress toward a sensitive system.
- **`tp-security-log-cleared`** - Security event log cleared at 3am by a user account. Clearing the security log is anti-forensics; something preceded it.
- **`tp-defender-disabled-then-download`** - Defender real-time protection disabled, then a download cradle. Defense evasion followed by tool transfer.
- **`tp-backdoor-local-admin`** - New local account created and added to Administrators. Unexpected local admin creation outside the provisioning path.
- **`tp-staged-exfil`** - Finance share archived with a password, then 80 MB leaves the network. Confirmed data leaving the organisation.
- **`tp-reverse-ssh-tunnel`** - Reverse SSH tunnel from a workstation to an external host. Reverse tunnels bypass inbound firewalling.
- **`tp-web-probe-single`** - One path-traversal probe against a public web server. Malicious intent, but one probe against a public host is routine noise.
- **`tp-departing-dev-destroys-repo`** - Branch protection removed, then the repository deleted. Destructive action against source control; restore and contain.
- **`tp-svchost-from-temp`** - svchost.exe running out of a user Temp directory. The real svchost only runs from System32.
- **`tp-schtasks-system-payload`** - Scheduled task created to run a Temp payload as SYSTEM. SYSTEM-level persistence for a binary in a temp path.
- **`tp-domain-recon-by-sales-user`** - Domain admin and DC enumeration from a sales laptop. Discovery is early-stage; worth working before it progresses.
- **`tp-cloud-admin-after-failures`** - Failed logins then AssumeRole into the production admin role. Privileged cloud access right after a credential attack.
- **`tp-phish-quarantined`** - Phishing email detected and quarantined, never opened. Malicious, but contained with no user interaction.
- **`fp-typo-then-success`** - One failed login followed by a success from the office IP. Ordinary user error.
- **`fp-helpdesk-systeminfo`** - Helpdesk runs systeminfo and ipconfig while on a ticket. Routine IT diagnostics by an IT account.
- **`fp-sccm-maintenance-task`** - SCCM agent registers a maintenance scheduled task. Endpoint management doing its job.
- **`fp-backup-shadow-copy`** - Backup software creates a shadow copy on the domain controller. Scheduled backup; engine rates this critical, which is the false alarm under test.
- **`fp-admin-ssh-port-forward`** - Engineer opens an SSH local port-forward to the bastion. Sanctioned access pattern via the corporate bastion.
- **`fp-it-anydesk-session`** - IT support starts an AnyDesk session for a user. Approved remote support by the IT team.
- **`fp-ansible-encoded-command`** - Ansible runs powershell -EncodedCommand over WinRM. Very likely Ansible, but encoded PowerShell deserves a check against the deploy log.
- **`fp-offboarding-remove-member`** - Org admin removes a departed employee from GitHub. Expected offboarding action by the right account.
- **`fp-ci-assumes-deploy-admin`** - CI pipeline role assumes the production admin role to deploy. The deploy identity doing a deploy; least-privilege concern, not an attack.
- **`fp-journald-vacuum-cron`** - Ops cron job vacuums old journald logs. Retention housekeeping; worth confirming it matches the retention policy once.
- **`fp-helpdesk-new-hire-account`** - Helpdesk creates a local account for a new hire's kiosk. Provisioning by IT; no admin group change.
- **`fp-marketing-video-upload`** - Marketing uploads a 60 MB video to the agency. Business transfer; volume alone is not exfiltration.
- **`fp-internal-vuln-scan`** - Internal vulnerability scanner probes the web server. Our own scanner.
- **`fp-support-bundle-archive`** - Admin creates a password-protected log bundle for a vendor ticket. Sanctioned but worth noting: logs leaving via a vendor channel.
- **`fp-dev-curl-download`** - Developer's build script uses curl in cmd to fetch a toolchain. Normal developer tooling from a reputable HTTPS source.
- **`amb-success-from-new-ip`** - Successful login from an unfamiliar residential IP. Nothing malicious observed; needs identity/geo context before judging.
- **`amb-finance-anydesk-offhours`** - Finance user installs AnyDesk at 10pm. Unsanctioned remote access on a finance endpoint is worth a call.
- **`amb-admin-encoded-powershell`** - IT admin runs encoded PowerShell interactively. Probably admin work, but encoded commands hide intent; confirm with the admin.
- **`amb-failed-logins-no-success`** - Eight failed logins from one external IP, no success. Hostile, but unsuccessful; watch for a follow-up success.
- **`amb-it-dc-enumeration`** - IT admin enumerates domain controllers and computers. Expected from the IT admin account and host.
